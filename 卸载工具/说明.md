# 卸载工具（本地修复候选）

Windows：先关闭 SRPRecorder2027.exe，再运行 卸载SRPRecorder2027.exe。默认保留 References、PersonalWorkspaceSRRec、研究 JSON 和外部自选文件夹；配置另存到 文档/SRPRecorder2027-数据备份 的独立目录。勾选删除数据才移除安装目录内的上述资料。只按程序文件清单移除，未知文件保留；不递归删除整个安装根。卸载器需要 .srprec-install 标记。失败时停止并显示错误。

Mac：uninstall-macos.command 对应已发布的 ResearchProgressRecorder.app 与 ~/Library/Application Support/ResearchProgressRecorder。终端执行 chmod +x uninstall-macos.command 后运行；输入 UNINSTALL 才把应用移入废纸篓。默认保留数据，只有再输入 DELETE 才把该用户数据目录移入废纸篓。外部文件夹和钥匙串令牌保留，可在钥匙串访问中手工移除 SRLogbook.github_token / ResearchProgressRecorder。未在真实 Mac 执行卸载。
